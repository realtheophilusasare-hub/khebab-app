# Khebab 🌮

**Build Your Own Khebab** — A custom kebab ordering web app built with React + Vite + Supabase.

## Features
- 4-step builder: Choose Meat → Add Veggies → Sauces & Spice → Review & Order
- Multi-select meat picker (Beef + Chicken combos allowed)
- Live skewer visualization panel
- Dynamic price estimation
- Popular add-ons carousel (upsell)
- Light/dark mode toggle
- Menu, Orders, About pages
- Cart & checkout flow
- Supabase backend for orders & inventory

## Tech
- React 18 + TypeScript
- Vite (build tool)
- Supabase (auth, database, real-time)
- CSS (no framework)
